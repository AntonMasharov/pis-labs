# Видеоотчёт lab06

[Видеоотчёт lab06-demo.mp4](lab06-demo.mp4) длится 1:37. В записи заявитель и специалист последовательно работают с одной заявкой в Chrome и отдельной демонстрационной базе SQLite. Русские пояснения встроены в видео. Их текст доступен в [субтитрах](lab06-demo.srt).

| Время | Роль | Что показано |
| --- | --- | --- |
| 00:04 | Заявитель | Регистрация по телефону и учебному SMS-коду `123456`. |
| 00:10 | Заявитель | Анкета, индивидуальный перечень, загрузка фотографии и первичная подача. |
| 00:21 | Специалист | Вход, очередь заявок, начало проверки и сохранение оценок трёх пунктов. |
| 00:32 | Специалист | Запрос сертификата и ИНН, переход в «Требует дополнения». |
| 00:39 | Заявитель | Вход, указание ИНН, загрузка сертификата, сохранение фотографии и отправка второй версии. |
| 00:51 | Заявитель | Перезагрузка страницы и просмотр сохранённых данных заявки. |
| 00:55 | Специалист | Вход, повторная проверка и выдача заключения. |
| 01:11 | Заявитель | Вход, «Оказанные услуги», получение заключения, история статусов, скачивание сертификата и просмотр первой версии с замечаниями. |
| 01:27 | Заявитель | Просмотр результата на узком экране. |

Использованы вымышленные телефоны/номер ИНН, условное изображение фотографии и PDF с пометкой DEMO. Они предназначены только для демонстрации хранения, передачи и проверки комплекта в учебном приложении.

Воспроизведение сценария: `python solution/tests/browser_demo.py --record` из корня репозитория. Дополнительные инструменты и условия перечислены в основном README.
