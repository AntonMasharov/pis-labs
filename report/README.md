# Видеоотчёт lab06

`lab06-demo.mp4` — реальное прохождение интерфейса в Chrome: обе роли последовательно работают с одной заявкой в отдельной демонстрационной SQLite-базе. Русские пояснения встроены в видеоряд; звуковая дорожка не требуется для просмотра. Исходные пояснения сохранены в `lab06-demo.srt`.

Порядок демонстрации:

1. Регистрация заявителя по телефону и учебному SMS-коду `123456`.
2. Анкета, расчёт индивидуального перечня, загрузка фотографии, первичная подача.
3. Вход специалиста, очередь, начало проверки, оценки трёх пунктов и их сохранение без решения.
4. Запрос сертификата и ИНН, переход в «Требует дополнения».
5. Вход заявителя, исправление анкеты, указание ИНН, загрузка сертификата, сохранение прежней фотографии.
6. Приём второй версии, перезагрузка страницы и чтение сохранённых данных.
7. Повторная проверка специалистом, положительные оценки, выдача заключения.
8. Вход заявителя, «Оказанные услуги», получение результата, история шести переходов, скачивание сертификата и просмотр первой версии с замечаниями.
9. Просмотр результата на узком экране и завершение демонстрации.

Использованы вымышленные телефоны/номер ИНН, условное изображение фотографии и PDF с пометкой DEMO. Они предназначены только для демонстрации хранения, передачи и проверки комплекта в учебном приложении.

Воспроизведение сценария: `python solution/tests/browser_demo.py --record` из корня репозитория. Дополнительные инструменты и условия перечислены в основном README.
